# Shopify Stock Analysis – Power BI

## Project Overview

This project is an interactive **Stock Analysis Dashboard** created using **Microsoft Power BI Desktop**. The dashboard performs Exploratory Data Analysis (EDA) on Shopify stock data using DAX calculations, moving averages, stock price trends, trading volume, slicers, and custom tooltips. 

## Objectives

* Analyze stock price data
* Calculate 20-day and 50-day Simple Moving Averages
* Compare moving averages using a crossover signal
* Analyze trading volume
* Create an interactive stock price dashboard
* Provide dynamic price metric selection
* Add date and relative date slicers
* Display detailed stock information using a custom tooltip

## Tools Used

* **Microsoft Power BI Desktop**
* **DAX**
* **Stock Dataset**
* **Data Visualization**
* **Power BI Slicers**
* **Field Parameters**
* **Custom Tooltips**

## Dashboard Features

* Close Price trend chart
* 20-Day SMA
* 50-Day SMA
* MA Crossover Signal
* Trading Volume analysis
* Volume 20 SMA
* Date Range Slicer
* Relative Date Slicer
* Price Metric Selector
* KPI Cards
* Interactive Zoom Slider
* Custom Stock Tooltip

## Price Metric Selector

The dashboard allows users to select:

* High Price
* Low Price
* Close Price
* Open Price

## Interactive Filters

Users can filter the dashboard using:

* Date Range
* Relative Date
* Price Metric

## Custom Tooltip

The custom tooltip displays:

* Open Price
* High Price
* Low Price
* Close Price
* Trading Volume
* Daily Change %


## Outcome

The project provides an interactive Power BI dashboard for exploring Shopify stock prices and trading volume. DAX-based moving averages and interactive Power BI features make it easier to examine stock trends over different time periods.
